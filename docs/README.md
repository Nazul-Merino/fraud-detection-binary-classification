# Project Documentation

This directory contains the main technical reports and supporting documentation generated throughout the development of the fraud detection project.

## Documents

### Fraud_Detection_Results_Showcase.pdf

Provides a consolidated summary of the project's main results, including model performance, threshold analysis, Precision-Recall and ROC evaluations, confusion matrix comparisons, and pipeline engineering outcomes. This document is intended to provide a high-level overview of the final analytical and engineering results obtained during the project.

### phase_1_exploratory_analysis_summary.pdf

Contains the detailed technical findings obtained during the exploratory analysis stage. The document summarizes the results generated from the notebooks located in the `notebooks/` directory, including data understanding, data quality assessment, class imbalance analysis, exploratory data analysis, feature engineering experiments, model development, and model evaluation activities.

### phase_2_production_architecture_summary.pdf

Contains the detailed technical findings and engineering decisions that guided the transition from exploratory analysis to a production-oriented fraud detection architecture. The document summarizes the rationale behind preprocessing strategies, feature engineering design, model selection, threshold optimization, cloud deployment considerations, and pipeline orchestration decisions.

## Relationship with the Notebooks

The analyses documented in `phase_1_exploratory_analysis_summary.pdf` and `phase_2_production_architecture_summary.pdf` are derived from the exploratory and modeling workflows implemented in the `notebooks/` directory. Together, these documents provide the detailed technical context behind the final results presented in `Fraud_Detection_Results_Showcase.pdf`.
