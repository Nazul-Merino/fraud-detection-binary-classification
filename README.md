# Credit Card Fraud Detection Pipeline

## Problem
Financial institutions face significant losses due to fraudulent transactions. Detecting fraud at the transaction level is a critical task.

## Objective
Develop a baseline binary classification model to identify whether a transaction is fraudulent or not.

## Approach (Planned)
- Data preprocessing
- Feature engineering on transaction-level data
- Train baseline models (e.g., Logistic Regression, Random Forest)
- Model evaluation using appropriate metrics (ROC-AUC, Precision-Recall)

## Project Structure
- data/ → datasets
- notebooks/ → exploratory analysis and experiments
- src/ → reusable code
